# Teletexto para grabar tus videos (skill para Claude Code)

Una página que corre en tu computador y muestra el guion cerca de la cámara mientras grabas. Cada toma se guarda sola en una carpeta.

## Qué trae
- El guion avanza solo a tu ritmo de lectura, con velocidad y tamaño de letra ajustables.
- Cámara limpia, pantallas compartidas y marcas de tiempo guardadas por toma.
- Marcas al grabar para cortar después: «error», «repito», «esto no va».
- Un guion de ejemplo y una guía opcional de edición.

## Instalar
1. Descarga `skill-teletexto-generico.zip` desde este repositorio.
2. Descomprime la carpeta `teletexto/` dentro de `~/.claude/skills/`.
3. Pídele a Claude Code que levante el teletexto y abre la dirección local en Chrome (permite cámara y micrófono).

El zip trae un `INSTALAR.md` con el detalle. Las tomas quedan en `~/Desktop/teletexto-tomas` (o en la carpeta de la variable `TELETEXTO_GRABACIONES`).

Este es un ejemplo genérico. Si quieres un teletexto a la medida (tu marca, tus guiones, tu edición), escríbeme en IA Founders.
